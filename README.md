# RenaMind

*(commonly called "Rena")*

RenaMind is an AI architecture built to close a specific gap: a **central
intelligence** layer that coordinates specialized agents, secures their
access to tools and data, remembers what matters across their lifetime, and
stays observable and compliant while doing it — instead of a pile of
disconnected, single-purpose bots with no shared memory or oversight.

**Status:** early stage — architecture and roadmap phase. No functional
code yet. See [ROADMAP.md](ROADMAP.md) for the full design: subsystems,
build phases, and open questions.

## Core focus

- **Central intelligence** — one coordinating system, not scattered bots
- **Reliability** — async-first, observable, built to keep running
- **Accountability** — confidence-scored outputs, role-based access,
  auditable by design
